# Reserved backend boundary

Phase 1 implements no backend. This directory is reserved for the future Cloudflare Workers API after user approval. No endpoint, deployment configuration, production credential, or payment handler exists here.

Use the shared domain concepts as input to server rules, but never trust browser prices, clocks, roles, settlement buttons or balances. See `docs/reference/API_CONTRACT.md` and `docs/PRODUCTION_ROADMAP.md`.
